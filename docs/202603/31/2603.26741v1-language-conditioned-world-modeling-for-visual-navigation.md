## 摘要
我们研究了语言条件视觉导航（LCVN），其中具身智能体被要求仅根据初始的第一人称视角观察来遵循自然语言指令。在无法获取目标图像的情况下，智能体必须依靠语言来塑造其感知和连续控制，这使得对齐（grounding）问题变得尤为具有挑战性。我们将该问题建模为以语言指令为条件的开环轨迹预测，并推出了 LCVN 数据集。这是一个包含 39,016 条轨迹和 117,048 条经过人工验证指令的基准测试，支持在多种环境和指令风格下进行可复现的研究。利用该数据集，我们开发了 LCVN 框架，通过两个互补的模型系列将语言对齐、未来状态预测和动作生成联系起来。第一个系列结合了基于扩散的世界模型 LCVN-WM 和在世界模型潜空间中训练的 Actor-Critic 智能体 LCVN-AC。第二个系列 LCVN-Uni 采用了一种自回归多模态架构，可同时预测动作和未来观察。实验表明，这些系列具有不同的优势：前者提供了更具时间连贯性的轨迹展开（rollouts），而后者在未知环境中的泛化能力更强。综上所述，这些观察结果指出了在统一任务设置中共同研究语言对齐、想象和策略学习的价值，LCVN 为进一步研究语言条件世界模型提供了坚实的基础。代码可在 https://github.com/F1y1113/LCVN 获取。

## Abstract
We study language-conditioned visual navigation (LCVN), in which an embodied agent is asked to follow a natural language instruction based only on an initial egocentric observation. Without access to goal images, the agent must rely on language to shape its perception and continuous control, making the grounding problem particularly challenging. We formulate this problem as open-loop trajectory prediction conditioned on linguistic instructions and introduce the LCVN Dataset, a benchmark of 39,016 trajectories and 117,048 human-verified instructions that supports reproducible research across a range of environments and instruction styles. Using this dataset, we develop LCVN frameworks that link language grounding, future-state prediction, and action generation through two complementary model families. The first family combines LCVN-WM, a diffusion-based world model, with LCVN-AC, an actor-critic agent trained in the latent space of the world model. The second family, LCVN-Uni, adopts an autoregressive multimodal architecture that predicts both actions and future observations. Experiments show that these families offer different advantages: the former provides more temporally coherent rollouts, whereas the latter generalizes better to unseen environments. Taken together, these observations point to the value of jointly studying language grounding, imagination, and policy learning in a unified task setting, and LCVN provides a concrete basis for further investigation of language-conditioned world models. The code is available at https://github.com/F1y1113/LCVN.

*   **核心问题**：如何在仅给定**初始第一人称视角观察**和**自然语言指令**的情况下，让具身智能体实现长程视觉导航？

*   **研究动机**：现有的世界模型多关注视觉预测，与策略学习脱节；而多模态大模型（MLLM）在处理长程轨迹预测时效率较低。本文旨在通过“语言条件下的世界建模”，将感知、想象（预测未来状态）与控制统一起来，并解决在缺乏目标图像时的语言对齐（Grounding）难题。

### 2. 方法论：核心思想与关键技术
论文提出了两种互补的 LCVN 框架，旨在探索扩散模型与自回归模型在导航任务中的表现：

*   **LCVN-WM + LCVN-AC（基于扩散的世界模型系列）**：
    *   **LCVN-WM**：基于扩散 Transformer（DiT）构建。利用 **Diffusion Forcing (DF)** 技术，对上下文窗口内的潜变量施加不同强度的噪声，增强时间建模能力。它根据当前动作和语言指令预测下一帧的潜状态。
    *   **LCVN-AC**：在世界模型的潜空间内训练的 Actor-Critic 智能体。通过**潜路径对齐（Latent Plan Alignment）**，将专家轨迹压缩为潜计划（Latent Plan），并利用**内在奖励（Intrinsic Reward）**（衡量预测状态与专家状态的一致性）来优化策略。
*   **LCVN-Uni（自回归多模态系列）**：
    *   **核心思想**：将动作预测和视觉想象统一为一个序列建模任务。
    *   **技术细节**：基于 Chameleon/Anole-7B 架构，使用 VQ 标记器处理图像、BPE 处理文本、Bin 标记器处理连续动作。在单次前向传播中同时输出下一跳动作和下一帧观察，实现“边想边走”。
*   **LCVN 数据集**：构建了一个包含 3.9 万条轨迹的大规模数据集，涵盖 5 个真实机器人场景，并利用 Qwen-VL-2.5 生成了三种风格（简洁、复杂、地标导向）的 11.7 万条人工校验指令。

### 6. 主要结论与发现
*   **互补性**：基于扩散的模型（LCVN-WM）在**时间连贯性**和已知环境下的导航精度更高；而自回归模型（LCVN-Uni）在**未知环境**下的泛化能力显著更强。
*   **语言的作用**：语言指令不仅是目标指引，还能显著提升世界模型预测未来状态的语义一致性。
*   **地标的重要性**：包含明确地标的指令能大幅提升导航成功率，因为它们提供了更强的空间锚点。
*   **性能关联**：智能体的“想象”能力（预测精度）与其最终的导航表现呈正相关。

### 7. 优点
*   **任务创新**：提出了开环的语言条件视觉导航任务，摆脱了对实时环境反馈的依赖，更接近人类的认知模式。
*   **数据集贡献**：LCVN 数据集规模大、指令风格多样且经过人工校验，为该领域提供了高质量基准。
*   **双路径探索**：同时对比了扩散模型与自回归模型，给出了清晰的适用场景建议。
*   **技术融合**：成功将 Diffusion Forcing 和 Latent Actor-Critic 结合，解决了长程预测中的漂移问题。

### 8. 不足与局限
*   **分辨率与上下文的权衡**：在 LCVN-Uni 中，受限于 4096 的 Token 窗口，增加上下文帧数必须以降低单帧图像分辨率为代价，这限制了其感知精细度。
*   **推理延迟**：尽管附录提到了蒸馏技术，但扩散模型的多步去噪过程在实时机器人部署中仍面临计算压力。
*   **开环限制**：虽然开环规划展示了强大的想象力，但在极度复杂的动态环境中，缺乏闭环修正可能会导致误差累积。
*   **数据偏差**：虽然涵盖了多种场景，但主要集中在室外和走廊等结构化环境，对极端复杂地形（如废墟、茂密丛林）的覆盖可能不足。
