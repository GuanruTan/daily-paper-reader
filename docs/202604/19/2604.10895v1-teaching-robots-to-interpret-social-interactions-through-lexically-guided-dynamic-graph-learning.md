## 摘要
一个机器人若要被称为具有社交智能，必须能够从用户的当前行为中推断其内部状态，预测用户的未来行为，并在需要时做出适当反应。在这项工作中，我们通过建模用户内部状态（隐变量）与动作（可观测状态）之间的动态关系，研究如何赋予机器人这种社交智能。我们的前提是，这些状态源于相同的底层社会认知过程，并相互动态影响。受认知科学理论的启发，我们提出了一种名为 SocialLDG 的新型多任务学习框架，该框架显式地建模了表现为六个不同任务的状态之间的动态关系。我们的框架利用语言模型为每个任务引入词汇先验，并采用动态图学习来建模随时间演化的任务亲和力。SocialLDG 具有三个优势：首先，它在两个公开的挑战性人机社交互动数据集上达到了最先进的性能；其次，它通过无缝学习新任务且不产生灾难性遗忘，支持强大的任务可扩展性；最后，得益于对任务亲和力的显式建模，它为不同互动如何随时间展开，以及在人类决策过程中内部状态与可观测动作如何相互影响提供了深入见解。

## Abstract
For a robot to be called socially intelligent, it must be able to infer users internal states from their current behaviour, predict the users future behaviour, and if required, respond appropriately. In this work, we investigate how robots can be endowed with such social intelligence by modelling the dynamic relationship between user's internal states (latent) and actions (observable state). Our premise is that these states arise from the same underlying socio-cognitive process and influence each other dynamically. Drawing inspiration from theories in Cognitive Science, we propose a novel multi-task learning framework, termed as \textbf{SocialLDG} that explicitly models the dynamic relationship among the states represent as six distinct tasks. Our framework uses a language model to introduce lexical priors for each task and employs dynamic graph learning to model task affinity evolving with time. SocialLDG has three advantages: First, it achieves state-of-the-art performance on two challenging human-robot social interaction datasets available publicly. Second, it supports strong task scalability by learning new tasks seamlessly without catastrophic forgetting. Finally, benefiting from explicit modelling task affinity, it offers insights on how different interactions unfolds in time and how the internal states and observable actions influence each other in human decision making.

#### 1. 核心问题与整体含义（研究动机和背景）
社交机器人若要实现真正的“社交智能”，必须能够像人类一样，从观察到的行为中推断用户的内部心理状态（如意图、态度），并预测其未来行为。目前大多数社交机器人是“反应式”的，且现有研究通常将意图识别、动作识别等任务视为孤立或具有固定关系的任务。
**研究动机：** 本文认为意图、态度和动作是同一社会认知过程（受认知科学中“并行约束满足理论”启发）的组成部分，它们之间存在动态的、随时间演化的相互影响。因此，论文旨在开发一种能够显式建模这些任务间动态亲和力的多任务学习（MTL）框架。

#### 2. 方法论：核心思想与关键技术
论文提出了 **SocialLDG** 框架，其核心思想是利用词汇先验引导动态图学习，以联合预测六项社交感知任务。
*   **输入与编码：** 使用 AlphaPose 提取全身 133 个关键点，通过一个时空编码器（空间 GAT + 时间 Transformer）生成社交信号表示 $Z$。该编码器通过自监督自编码器预训练，并采用“置信度感知 MSE 损失”来处理噪声。
*   **词汇任务令牌（Lexical Task Tokens）：** 使用冻结的 SciBERT 模型对每个任务的文本描述（如“检测用户是否正在与我接触”）进行编码，生成初始任务令牌，为图节点提供语义先验。
*   **语义边生成器（Semantic Edge Generator）：** 结合社交信号 $Z$ 和任务令牌，动态生成边缘偏置矩阵 $B$。这允许模型根据当前的社交上下文（如用户是热情还是冷淡）调整任务间的关联强度。
*   **动态图变换器（Dynamic Graph Transformer）：** 将任务视为图节点，通过注意力机制学习任务亲和力矩阵 $A$。该矩阵是动态的，随时间步变化，指导任务间的信息交换。
*   **六项任务：** 当前/未来接触检测、意图推断、态度分类、当前/未来动作识别。

#### 3. 实验设计
*   **数据集：** 整合了两个具有挑战性的机器人视角数据集：**JPL-Social**（包含 9 种社交动作及意图、态度标注）和 **HARPER**（四足机器人视角，包含复杂的避障和碰撞场景）。
*   **Benchmark 与对比方法：**
    *   **硬参数共享：** Parallel  baseline。
    *   **门控软共享方法：** MMoE, PLE, DSelect-K。
    *   **任务关联建模方法：** UniT, HiPro, AssociationGraph。
*   **评估指标：** 各子任务的 F1 分数及平均 F1 分数。

#### 4. 资源与算力
*   **硬件：** 使用单张 **NVIDIA RTX 4070** GPU 进行训练和推理。
*   **训练细节：** 采用预训练 + 端到端微调策略。使用了 AdamW 优化器，Batch Size 为 128，包含 5 个 Epoch 的线性预热及基于验证集表现的动态衰减。
*   **数据增强：** 通过随机裁剪和水平翻转，将原始约 2,500 个样本增强至 30,000 个以上。

#### 5. 实验数量与充分性
*   **实验规模：** 进行了 SOTA 对比实验、消融实验（针对边缘偏置、任务提示注入等模块）、不同文本编码器对比、不同骨干网络对比以及损失函数对比。
*   **任务可扩展性实验：** 专门设计了三组实验（A/B/C 设置），验证模型在引入新任务时是否会发生灾难性遗忘。
*   **充分性评价：** 实验设计较为全面，涵盖了性能、鲁棒性、可解释性和可扩展性。通过可视化任务亲和力矩阵随时间的变化，增强了结果的说服力。

#### 6. 主要结论与发现
*   **性能领先：** SocialLDG 在平均 F1 分数（85.25%）上优于所有对比的 MTL 方法，尤其在需要深度推理的“未来动作预测”任务上提升显著。
*   **动态关联：** 实验证明任务间的关系不是固定的。例如，在互动开始和结束的瞬间，任务亲和力矩阵会发生剧烈变化，这可以作为识别互动阶段的信号。
*   **词汇引导有效：** 引入 SciBERT 的科学文本先验显著提升了模型区分相似任务的能力。
*   **快速扩展：** 模型仅需 1 个 Epoch 的微调即可快速学习新任务，且对旧任务的性能保持良好。

#### 7. 优点
*   **可解释性：** 显式建模任务亲和力矩阵，使机器人对社交互动的理解过程不再是黑盒，能够展示内部状态如何影响外部动作。
*   **认知启发：** 将心理学理论（PCS）转化为计算模型，使多任务处理更符合人类的社会认知逻辑。
*   **灵活性：** 词汇引导机制使得模型能够轻松适应不同的任务定义，具有很强的工程实用性。

#### 8. 不足与局限
*   **数据局限性：** 所使用的两个数据集均为“表演式”社交互动（Acted），而非自然发生的自发性互动，真实场景中的噪声和不确定性可能更高。
*   **时间平滑性：** 框架目前没有强制执行时间连续性或平滑约束，在某些极短的观察窗口内可能会出现预测抖动。
*   **计算开销：** 虽然在 RTX 4070 上可运行，但其参数量和推理延迟在对比方法中处于较高水平（尽管仍在实时处理范围内）。
