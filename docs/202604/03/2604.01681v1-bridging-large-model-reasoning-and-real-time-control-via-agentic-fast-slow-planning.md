## 摘要
大型基础模型为自主系统提供了强大的推理能力，但将语义意图映射到可靠的实时控制仍具挑战。现有方法要么 (i) 让大语言模型 (LLM) 直接生成轨迹——这种方式脆弱、难以验证且易产生延迟；要么 (ii) 在线调整模型预测控制 (MPC) 的目标——这混合了慢速深思熟虑与快速控制，模糊了接口界限。我们提出了智能体快慢规划（Agentic Fast-Slow Planning），这是一个在自然时间尺度上解耦感知、推理、规划和控制的分层框架。该框架包含两个桥梁：Perception2Decision 使用车载视觉语言模型 (VLM) 检测器将场景压缩为以自我为中心的拓扑结构，然后通过云端 LLM 决策器将其映射为符号化驾驶指令，在保持可解释性的同时减少了带宽和延迟；Decision2Trajectory 将指令转换为可执行路径，其中语义引导的 A* 算法将源自语言的软成本嵌入经典搜索中，使解偏向可行轨迹，而智能体细化模块则利用反馈和记忆来调整规划器的超参数。最后，MPC 实时跟踪轨迹，并针对困难情况提供可选的云端引导参考。在 CARLA 中的实验表明，与纯 MPC 和 A* 引导的 MPC 基准相比，智能体快慢规划提高了扰动下的鲁棒性，横向偏差减少了高达 45%，完成时间缩短了 12% 以上。代码可在 https://github.com/cjychenjiayi/icra2026_AFSP 获取。

## Abstract
Large foundation models enable powerful reasoning for autonomous systems, but mapping semantic intent to reliable real-time control remains challenging. Existing approaches either (i) let Large Language Models (LLMs) generate trajectories directly - brittle, hard to verify, and latency-prone - or (ii) adjust Model Predictive Control (MPC) objectives online - mixing slow deliberation with fast control and blurring interfaces. We propose Agentic Fast-Slow Planning, a hierarchical framework that decouples perception, reasoning, planning, and control across natural timescales. The framework contains two bridges. Perception2Decision compresses scenes into ego-centric topologies using an on-vehicle Vision-Language Model (VLM) detector, then maps them to symbolic driving directives in the cloud with an LLM decision maker - reducing bandwidth and delay while preserving interpretability. Decision2Trajectory converts directives into executable paths: Semantic-Guided A* embeds language-derived soft costs into classical search to bias solutions toward feasible trajectories, while an Agentic Refinement Module adapts planner hyperparameters using feedback and memory. Finally, MPC tracks the trajectories in real time, with optional cloud-guided references for difficult cases. Experiments in CARLA show that Agentic Fast-Slow Planning improves robustness under perturbations, reducing lateral deviation by up to 45% and completion time by over 12% compared to pure MPC and an A*-guided MPC baseline. Code is available at https://github.com/cjychenjiayi/icra2026_AFSP.

论文探讨了如何将**大模型（LLM/VLM）的高级语义推理能力**与**自动驾驶的实时底层控制**有效结合。
*   **研究动机**：现有方法存在两大缺陷：一是直接用 LLM 生成轨迹，输出结果脆弱、难以验证且延迟高；二是利用 LLM 在线调整 MPC 参数，导致慢速推理与快速控制混杂，接口模糊。
*   **核心思想**：提出 **Agentic Fast-Slow Planning (AFSP)** 框架，借鉴认知科学中的“双系统”理论，在不同时间尺度上解耦感知、推理、规划和控制，通过两个关键“桥梁”实现语义到动作的平滑转换。

### 2. 方法论：核心思想与关键技术
该框架分为三层：推理层（慢速）、规划层（中速）和控制层（快速）。
*   **Perception2Decision（感知到决策桥梁）**：
    *   **车载端（VLM 拓扑检测器）**：将原始图像压缩为以自我为中心的拓扑图（包含物体类别、距离、方位等），减少带宽需求。
    *   **云端（LLM 决策器）**：基于拓扑图进行思维链（CoT）推理，输出符号化指令（如 LEFT, RIGHT, KEEP）和驾驶风格。
*   **Decision2Trajectory（决策到轨迹桥梁）**：
    *   **语义引导 A* 算法**：在经典 A* 搜索中引入“语义软成本”（Semantic Soft Costs）。根据 LLM 指令的完成情况（正确、延迟、错误、过度执行）分配不同权重，引导搜索算法生成符合语义意图且物理可行的路径。
    *   **智能体细化模块（Agentic Refinement）**：利用 LLM 作为智能体，根据规划反馈和历史记忆自动调整 A* 算法的超参数，替代人工调参。
*   **实时控制**：采用 **云端引导的 MPC**。在常规情况下由本地参考路径控制，在复杂场景下切换至云端生成的全局参考轨迹，确保实时性和安全性。

### 6. 主要结论与发现
*   **性能提升**：AFSP 框架在 CARLA 实验中表现优异，相比纯 MPC，**最大横向偏差降低了约 45%**，**任务完成时间缩短了 12% 以上**。
*   **鲁棒性**：语义引导的 A* 算法能有效纠正地图偏移带来的规划偏差，使车辆在扰动下仍能保持符合意图的行驶路径。

### 7. 优点（亮点）
*   **尺度解耦设计**：科学地分离了慢速语义推理与快速实时控制，解决了 LLM 难以直接介入实时控制循环的难题。
*   **语义软成本接口**：创新性地将语言指令转化为 A* 算法的代价函数，既保留了经典算法的确定性，又引入了 LLM 的灵活性。
*   **闭环自调参**：引入智能体模块自动优化规划器参数，增强了系统对长尾场景的自适应能力。

### 8. 不足与局限
*   **云端依赖性**：系统高度依赖云端 LLM 的实时响应，若发生网络中断或高延迟，系统的决策能力将受限（虽然有本地 MPC 兜底，但高级智能会丧失）。
*   **仿真与现实差距**：实验完全在 CARLA 模拟器中进行，尚未在真实道路或复杂动态交通流中验证其 Sim-to-Real 的迁移能力。
*   **指令集有限**：目前的语义指令（左转、右转、保持）相对简单，对于极其复杂的交互场景（如无保护左转中的博弈）可能需要更精细的指令定义。
